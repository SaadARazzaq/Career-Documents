## 🎯 Overview

This repository contains scanned and compiled versions of all my professional and educational documents in a single, organized location. It serves multiple purposes:

- **Professional Networking** - Easy sharing of credentials with recruiters, employers, and educational institutions
- **Digital Archive** - Secure backup of important certificates and documents
- **Accessibility** - Quick access to any document through an intuitive web interface
- **Verification** - Centralized location for verifying educational qualifications and certifications
- **Portfolio Enhancement** - Demonstrates organizational skills and professionalism

The repository includes a beautiful, interactive **Document Viewer** (`index.html`) that allows visitors to browse, search, and download all documents with an elegant user interface.

## 📥 How to Use

### Viewing Documents
1. Open `index.html` in your browser
2. Browse the featured documents or search for specific ones
3. Click **"View"** to open a document in a new tab
4. Click **"Download"** to save the document to your device

### Searching Documents
1. Use the search bar to find documents by name or keywords
2. Results update in real-time as you type
3. Click "Clear Search" to reset

### Filtering by Category
1. Click on category tabs (Root Documents, Certifications, University, etc.)
2. View only documents in that category
3. Switch between categories instantly

### Downloading Multiple Documents
- Click the "Download" button on any document card
- You can download multiple documents sequentially
- All files are PDFs and can be opened with any PDF reader
